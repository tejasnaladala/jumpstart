# Parking Lot P005: One high-signal match per drop instead of three

Run 11, score 91 (-3 from best 94). Discarded.

## What was tested

Closer to Ditto's purest form. One curated match per drop. Forces quality over quantity.

## Why it failed

User said "three people worth meeting" and that is the locked spec language. Cutting to one weakens thesis_alignment because the user's stated goal is breadth-of-introduction within the cohort, not single-match dating.

## Why it might come back

This is a parameter, not a vision question. Once Jumpstart has data, run a separate autoresearch session with this as the metric: drop format A (one match) vs B (three matches), measure intro_request_rate and meeting_useful_rate per drop, pick the winner.

## Conditions for revisit

- Phase 2 starts (after week 1)
- Eval suite is in place
- 100 active users have received at least 4 drops
- A/B framework allows running both formats in parallel
